# SuperMe

> SuperMe is a professional network for the AI age that connects users with expert knowledge from real professionals. It offers Work Groups (curated panels of founders and executives with AI profiles trained on their actual work), My Agent (a personal AI assistant that finds relevant experts and synthesizes their perspectives), and Group Chat (real-time discussions with multiple AI profiles). SuperMe exposes an official, OAuth-protected hosted MCP server so its network can be used from within Claude, ChatGPT, and Cursor. Backed by Forerunner Ventures and Greylock.

This llms.txt was generated by the API Evangelist enrichment pipeline from the SuperMe public surface and the artifacts captured in this repository. SuperMe does not publish its own /llms.txt.
